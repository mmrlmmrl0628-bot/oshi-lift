# ○○○クリニック / 推し活女子向け 糸リフトLP

転職活動用の自主制作。30代前半の推し活女性を想定した、スマートフォン優先の縦長LPです。

## 見る方法
index.html をブラウザで開きます。assets フォルダは同じ場所に置いてください。別添の oshi-lift-preview.html は画像内蔵の単体ファイルです。

## Vercelで公開する方法
このフォルダの中身（index.html、assets、vercel.json）をGitHubリポジトリのルートに置き、Vercelでインポートします。Framework Preset は Other。Build Command は空欄、Output Directory は `.`。外部ライブラリやビルドは不要です。
既存サイトに反映する場合は、そのサイトのソースに差し替えてデプロイします。現時点ではVercelへの公開は行っていません。

## 実装
- HTML/CSS/JavaScript。文字は画像に含めず、鮮明さと編集性を確保。
- 提供キャラクター、うちわを持つオリジナル女子の3Dイラスト。
- 画面下部の固定予約ボタン、予約デモダイアログ、開閉式FAQ。
- ダイアログは閉じるボタン、Esc、背景クリックに対応。
- 写真はAI生成の架空比較。症例や治療効果と誤認しない表記。
- 予約システム未接続。個人情報の収集なし。

## 実運用前の差し替え
院名、料金・総額、医師と医院情報、医師監修の施術説明、実際に使用する製品情報、予約先URLを確定する必要があります。提供キャラクターの利用権も確認してください。

## 表現と資料
「若いファンに負けたくない」は読者の気持ちとして提示。施術の緊急性や将来のたるみ予防は断定していません。
参考LPはページ取得ができなかったため、その構成や素材はコピーしていません。
施術の一般説明・副作用の確認に用いた公式情報：
https://www.s-b-c.net/ （検索結果で施術リスクの表記を確認）
公開前には実際の施術内容に基づく医師の確認が必要です。

## 画像生成仕様
Built-in imagegenを使用。Hero: 提供ナースキャラクターを保ち、30代前半の推し活女子を同じつやのある3D表現で配置。「こっち見て♡」うちわ、各人物の腕と手は2本、ピンクと白、余分な文字なし。
Comparison: 同じ架空の32歳日本人女性、同じ角度・照明・髪型・表情、自然な肌、控えめな輪郭差、文字なし。実際の施術結果を再現するものではありません。

# 株式会社Lim / 不動産売却査定LP（lim/）

家や土地を売りたい人向けの、SNS集客用の売却査定LP。構成は大手不動産会社の売却査定LP（ヒーロー → かんたん入力 → 選ばれる理由 → CTA → お客さまの声 → FAQ → CTA）を参考にしています。
内容は公式サイト（https://www.lifeismore.co.jp）と SNS戦略 第1回ミーティング議事録で整理したLimの強みをもとに作成。ロゴ・イラストは公式サイトの素材を `lim/assets/` に配置。Vercelでは `/lim` で表示されます。

- フォント：Noto Sans JP（公式サイトと同じ）＋ 英字見出しに Anton。`lang="ja"` と合わせ、Android などで中国語字形にならないようにしています
- フォーム：物件の種類 → 所在地（全国47都道府県）→ 「無料査定を申し込む」でご連絡先入力ダイアログ → 完了画面
- 選ばれる理由：①ハウスメーカー出身で建物の価値まで伝えられる ②家づくり中のお客さまと提携24社のネットワーク ③住み替えもワンストップ ④専属FP ⑤相談しやすさ・会社としての安心感

## 確認済み（中嶋さん）
- 査定・相談は無料、相談のみもOK
- 土地探しのご相談が数多く寄せられている
- 対応エリアは全国

## 仮で入れているもの（ページ内に黄色の「仮」ラベルあり）
- 実績グラフ2点（査定価格以上で成約／3ヶ月以内に成約）の数値 → 実績データ確定後に差し替え
- ご売却されたお客さまの声3件 → 実際の声が集まったら差し替え
- ご連絡先入力フォーム → `lim/index.html` の `FORM_ENDPOINT` に送信先（フォーム受付サービスやGoogle Apps ScriptなどのURL）を設定。未設定のあいだは送信せず、完了画面に「仮フォーム」の注記を表示
